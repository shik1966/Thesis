# Defense Presentation Checklist

## **Technical Preparation**

### **Slides & Materials**
- [ ] Presentation slides finalized and saved in multiple formats (PowerPoint, PDF)
- [ ] Backup copies on USB drive, cloud storage, and email
- [ ] All images and figures properly embedded (not linked)
- [ ] Slide transitions and animations tested
- [ ] Remote clicker/presenter tested with laptop
- [ ] Backup slides prepared for detailed questions

### **Equipment Check**
- [ ] Laptop fully charged with power adapter
- [ ] HDMI/VGA adapters tested with projector
- [ ] Microphone tested (if needed)
- [ ] Internet connection verified (if online elements)
- [ ] Backup laptop or colleague's laptop identified
- [ ] All files accessible offline

### **Content Verification**
- [ ] All numbers and results double-checked against thesis
- [ ] Citations and references accurate
- [ ] Spelling and grammar checked
- [ ] Slide timing practiced (18-20 minutes target)
- [ ] Transitions between slides are smooth
- [ ] Technical terms defined clearly

## **Presentation Practice**

### **Rehearsal Checklist**
- [ ] Full presentation practiced at least 3 times
- [ ] Timing recorded for each section
- [ ] Practice with actual slides, not notes
- [ ] Recorded yourself to check pace and clarity
- [ ] Practiced with a friend/colleague for feedback
- [ ] Q&A scenarios practiced

### **Key Messages Memorized**
- [ ] Opening statement (first 30 seconds)
- [ ] Main contribution statement
- [ ] Key results summary
- [ ] Closing statement
- [ ] Elevator pitch version (2 minutes)

## **Content Mastery**

### **Your Thesis**
- [ ] Can explain any figure or table in detail
- [ ] Know all methodology details thoroughly
- [ ] Can discuss limitations honestly
- [ ] Can explain statistical significance
- [ ] Can compare to related work
- [ ] Understand implications of your results

### **Background Knowledge**
- [ ] SegNet architecture details
- [ ] Classical feature detection principles
- [ ] Brain tumor segmentation background
- [ ] BraTS dataset characteristics
- [ ] Evaluation metrics (Dice, IoU, HD95)
- [ ] Medical imaging fundamentals

## **Question Preparation**

### **Anticipated Questions**
- [ ] "Why not use 3D instead of 2D?"
- [ ] "How does this compare to state-of-the-art?"
- [ ] "What about statistical significance?"
- [ ] "Computational overhead concerns?"
- [ ] "Clinical validation plans?"
- [ ] "Limitations of your approach?"
- [ ] "Future work directions?"

### **Technical Deep Dives**
- [ ] Can explain each filter's mathematical basis
- [ ] Know SegNet vs U-Net differences in detail
- [ ] Can discuss class imbalance handling
- [ ] Understand evaluation policy choices
- [ ] Can explain RGB fusion rationale
- [ ] Know dataset preprocessing steps

## **Day Before Defense**

### **Final Preparations**
- [ ] Full dress rehearsal completed
- [ ] All materials packed and ready
- [ ] Defense location/online setup confirmed
- [ ] Committee members' names and titles memorized
- [ ] Backup plans for technical issues ready
- [ ] Good night's sleep planned

### **Materials to Bring**
- [ ] Laptop with presentation
- [ ] Power adapter and cables
- [ ] USB backup drive
- [ ] Printed thesis copy
- [ ] Notebook for notes during Q&A
- [ ] Water bottle
- [ ] Professional attire ready

## **Day of Defense**

### **Morning Preparation**
- [ ] Healthy breakfast eaten
- [ ] Arrive 30 minutes early
- [ ] Test all equipment one final time
- [ ] Review key points (don't over-rehearse)
- [ ] Positive mindset and confidence check

### **During Defense**
- [ ] Speak clearly and at appropriate pace
- [ ] Make eye contact with committee
- [ ] Use pointer effectively for figures
- [ ] Stay calm during Q&A
- [ ] Answer "I don't know" honestly when appropriate
- [ ] Thank committee at beginning and end

## **Emergency Contingencies**

### **Technical Issues**
- [ ] Plan B: Present from backup laptop
- [ ] Plan C: Present from committee member's laptop
- [ ] Plan D: Present from printed slides if needed
- [ ] Have tech support contact ready

### **Stress Management**
- [ ] Deep breathing exercises practiced
- [ ] Positive self-talk prepared
- [ ] Support person identified (friend/family)
- [ ] Celebration plan ready (regardless of outcome)

## **Post-Defense**

### **Immediate Actions**
- [ ] Thank committee personally
- [ ] Note any required revisions
- [ ] Celebrate appropriately
- [ ] Contact supervisor with update
- [ ] Thank supporters and helpers

### **Follow-up**
- [ ] Submit any required revisions
- [ ] Update LinkedIn/CV with degree
- [ ] Consider publication opportunities
- [ ] Maintain relationships with committee
- [ ] Plan next career steps
